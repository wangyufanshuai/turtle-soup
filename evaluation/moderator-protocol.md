# C01 正式 Fun Gate 主持协议

状态：真人参与数 `0`，正式评测 `pending`。

## 开场主持词

> 你要调查一件短案件。系统的回答是在验证事实，不是在告诉你答案。请尽量独立完成；我只会解释操作，不会提示案件事实。

主持人只能解释按钮和操作方式，不得提供对象名、问题方向、正确理论、证据组合或缺口答案。

## 必记事件

- 会话开始与结束时间；
- 首次有效操作时间；
- 是否理解提问循环；
- 歧义恢复、重复提问、错误理论与提示使用；
- 是否形成因果链、是否正式结案、是否打开回放；
- 中断原因与测试者原话。

评测后把产品导出的文件放入 `test-data/fun-gate/`，运行 `npm run aggregate:fun-gate -- test-data/fun-gate`。不得手工补造缺失记录。
