# C02–C12 公平性抽测方案

前置条件：C01 正式 Fun Gate 达标或共享交互修订完成。当前状态 `pending`。

- 每案至少抽测 2 位不知道答案的玩家；高级案件至少 1 位从未玩过海龟汤。
- 每名测试者最多测试 3 案，顺序使用平衡轮换，避免疲劳与学习效应集中到后期案件。
- 每案必须观察：关键事实是否公平可问、错误理论是否能被可得证据排除、缺口反馈是否泄底、结案回放是否与玩家证明一致。
- 任何不可逆语义误路由、隐藏必要事实不可达或错误理论被判 solved，均为该案公平性失败。
- 结果按 case / fairness / language / interaction / presentation 分类；不得把作者解释当作玩家成功。
