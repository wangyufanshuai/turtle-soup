## 本轮变化

- 首页加入无强制解锁墙的九案黄金路线：C01 → C03 → C13 → C06 → C17 → C24 → C33 → C48 → C60，并以本地结案/精通记录推荐下一案。
- 新增三级主动提示：概念方向、证据类别、证明义务类别；提示不包含事实 ID、事件顺序、答案或下一条标准问题。
- 新增有限预算黑箱玩家：12 类 persona × 60 案，共 720 条公开协议轨迹；允许 `solved`、`abandoned` 和 `budget_exhausted`，不再用无预算穷举制造 100% 结案。
- C25、C37 仅通过 presentation patch 与 alias pack 校准，有效提问率分别为 0.9583 与 0.9750，歧义和复合反事实继续 fail-closed。
- C33、C36、C48、C60 手机端一次显示一个推理任务；已填满板和已闭合事件链可折叠，缺口类别与提交入口固定在长链前方。
- 修复 C13–C60 音景映射回退问题；60 案具有 60 个唯一程序化音景身份，声音全部为装饰信息。
- 修复 WebKit 多板自动化的重渲染竞态，并为截图增加 resting skip-link 断言。
