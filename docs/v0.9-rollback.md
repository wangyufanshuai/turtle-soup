# TURTLE SOUP v0.9 回滚说明

1. 部署前保留上一版完整静态目录、ZIP 与 `release-manifest.json`，并核对 SHA-256。
2. Web/PWA 必须原子替换整个目录，禁止只覆盖 HTML、Worker、CSS 或 `sw.js`。
3. v0.9 使用 `black-soup-v09-gm1`。新 Service Worker 完整缓存后进入 waiting，只有玩家点击“应用更新”才激活。
4. 若发现 P0/P1，恢复上一目录与上一版 Service Worker；不得让 v0.9 壳与旧案件 Worker 混用。
5. 存档继续通过 `schemaVersion + caseId + caseVersion + contentHash` 验证。不兼容存档 fail-closed，并允许从本地备份重新导入。
6. 音景设置只存在本地偏好；关闭或移除音景不会影响案件命令日志、真相判定或存档兼容性。
7. itch.io 预览包包含独立的子路径适配层。回滚 itch 构建时必须替换整个 ZIP，不要把 `itch-runtime.js` 单独复制到 Web/PWA 包。
8. C01 Fun Gate 包不得在回滚时混入 C02–C12 路由；重新核对 `includedCaseRoutes`。
9. 回滚后至少执行 `npm run check`、`verify:freeze`、`audit:static`、`audit:browsers`、`audit:itch` 和 `scan:release`。
