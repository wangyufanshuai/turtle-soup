# TURTLE SOUP v0.9 已知限制

- 真人参与数仍为 0。自动化不能证明案件好玩、易懂、节奏合适、音景悦耳或具有市场竞争力。
- 本机设备探测未发现 ADB Android、iPhone/iPad 或低性能候选设备；真实 Android Chrome、iOS Safari 和低端硬件均保持 `pending`。
- Playwright WebKit/Windows 没有 Web Audio；静默降级已经通过，但它不等同于真实 iOS Safari 的音频解锁、来电中断和后台恢复测试。
- 12 套音景是紧凑的程序化合成层，没有配音或写实录音资产；混音审美仍需真人和真实扬声器/耳机验证。
- 音频始终是装饰性反馈，关闭声音仍可完整解谜；因此不会用音频制造独占线索。
- 74 张视觉基线验证状态可达、尺寸、区分度和溢出，不代表真人认为画面达到顶级独立游戏审美。
- itch.io 包通过等价嵌套子路径测试，但尚未实际上传到 itch.io 接受渠道审核；该预览包有意关闭 PWA 注册。
- 本机静态服务器与 4× CPU 仿真不代表真实 CDN、弱网、低内存、发热降频或老旧手机性能。
- Worker 隔离避免 UI、日志和 React DevTools 意外泄底，但离线真相仍可被主动反编译；产品不宣称 DRM。
- 中文确定性语义匹配有意 fail-closed，真实玩家仍可能使用现有语料之外的表达。
- v0.9 后停止继续用自动化“优化乐趣”；下一步必须是冻结 C01 真人 Fun Gate，再抽测 C02–C12。
