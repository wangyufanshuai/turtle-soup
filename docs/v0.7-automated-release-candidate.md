## 本轮修复

- 修复理论事件上移/下移时把公开事件 ID 写回内部状态的问题，并增加回归测试。
- 修复 C03 低置信问法“第二个影子是光造成的吗？”静默路由到“两个人”谓词的问题；现在强制进入二选一解释，且不写入问答记录。
- 为 C02–C12 补齐静音、减少动态和高对比设置；设置跨刷新保持，模态框支持焦点进入、循环和 Escape 关闭。
- 修复静态导出路径与 Service Worker 预缓存路径不一致导致的离线 P0；统一使用 trailing-slash 输出并升级为 `black-soup-v07-rc2` 缓存。
- 关闭案件选择页的自动预取，消除普通静态服务器上的动态 RSC 预取 404。
- 为 12 案补齐首次体验三步引导、案件专属问题提示、明确的拒绝/歧义/撤销反馈、证据检查/核实/关联状态和带来源的证明回放。
- 保持完整 `CaseFile`、事实图和证明证书仅位于 Worker；初始和结案玩家投影的禁止字段扫描均为 0 命中。

## 发布判断

可以继续进行无真人条件下的代码审查、文案校对、设备兼容和发布工程，但不能再用自动化提升“是否好玩”的置信度。正式公开发布仍应等待：

1. 冻结 12 案后执行 C01 正式 Fun Gate；
2. 根据 C01 结果只修共享交互与表达，不静默改写冻结真相；
3. 抽测 C02–C12 的公平性与语言理解；
4. 记录版本化修订并重新跑本报告全部检查。
