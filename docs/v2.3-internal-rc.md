# TURTLE SOUP v2.3 · Resolution Payoff Internal RC

状态：`internal-rc / human-evaluation-pending`

本候选版以 v2.2 为冻结基线，不修改 C01–C60 的真相、事件、事实、证明证书、canonical hash、胜负逻辑或 `SaveEnvelope.schemaVersion: 1`。本轮集中修复结案回报被编辑界面遮蔽、按需调查工具产生等待空洞，以及首页季节标签缺少标准键盘操作的问题。

## 本轮加固

- 结案后推断区立即切换为只读“结案档案”，不再先展示可编辑假设、推理板和证据按钮；
- 首屏直接呈现“你的证明成立”、公开结案统计、玩家自己的解释和逐拍证据回放；
- 结案统计仅使用 `PlayerProjection.debrief` 与玩家公开选择，不读取隐藏证明义务；
- 证据与推理工具在玩家接近使用时预热，首屏主包仍保持按需分块；
- 延迟加载占位缩短并明确说明调查状态不会改变；
- 首页季节标签支持方向键、Home、End，并采用单一 Tab 停靠点；
- 手机结案界面优先显示结案反馈和回放，不再停留在证明材料编辑清单。

## 验证边界

- 60 案冻结身份、存档重放、反泄漏和确定性结案必须相对 v2.2 不变；
- 浏览器覆盖 Chromium、Firefox、WebKit，桌面 `1440×900` 与手机 `390×844`；
- AI 默认关闭、按需加载；无 Key、离线或端点失败仍可完整通关；
- 正式 Fun Gate 参与者仍为 `0`，创始人探索会话为 `1`；
- 自动化不能证明乐趣、审美、节奏、理解率、留存或市场适配。
