# TURTLE SOUP v0.7 问题清单

验证日期：2026-08-23

## 已关闭的 P0 / P1

| 级别 | 问题 | 处理 |
|---|---|---|
| P0 | 静态导出生成 `.html`，Service Worker 却预缓存尾斜杠路由，普通静态服务器离线不可可靠启动 | 启用 `trailingSlash`，重新生成目录 `index.html`，生产断网重开通过 |
| P1 | 时间链重排把公开事件 ID 写进内部草稿，投影可能产生 `event-unknown` | 改为写入 internal ID，增加专用回归测试 |
| P1 | C02–C12 没有静音、减少动态和高对比入口 | 增加共享本地设置和可键盘操作的设置对话框 |
| P1 | 首页预取动态案件 RSC，在普通静态服务器产生 404 | 案件链接关闭预取；生产控制台 0 error / 0 warning |
| P1 | C03 低置信“光造成影子”问法可能被静默解释为“台上有两个人” | 调整语义路由为强制歧义选择；新增回归测试并验证不增加 transcript |

自动化范围内没有未关闭的 P0 或 P1。

## 已知限制 / P2

- 确定性中文匹配有意 fail-closed，未命中的真实口语仍需要问题构建器或作者补语料。
- 语料 duplicate rate 为 15%–26%，主要来自同一核心问法的标点和外壳变体；覆盖验证有效，但不能当作 150 条完全独立的人类表达。
- C02–C12 当前没有独立音景；静音设置保持一致，但声音表现仍以 C01 为主。
- 浏览器截图使用 Chrome 和本机静态服务器；尚未完成 Safari/iOS 实机、低端 Android、Firefox 和 Edge 的实体设备检查。
- 本地加载时间不是线上 Core Web Vitals，也没有真实 CDN、弱网和首次冷缓存数据。
- 离线 Web 内容无法抵御主动反编译；Worker 边界防止意外泄底，不是 DRM。

## 只能由真人验证

以下指标保持 `pending`：

- 首次玩家是否理解“提问是在验证事实”；
- 5–20 分钟内形成正确因果链的比例；
- 无提示完成正式证明的比例；
- 满足感是否主要来自自己证明；
- 真实口语匹配是否导致放弃；
- 错误理论反馈是否被感知为公平而非泄底；
- C02–C12 的难度梯度、疲劳度、题材辨识度和连续游玩意愿。
