# TURTLE SOUP v2.0：无真人极限体验硬化 RC

状态：`internal-rc / human-evaluation-pending`

v2.0 不新增案件，也不修改 C01–C60 的事件、事实、证明证书、canonical hash 或胜负逻辑。它把 v1.9 创始人试跑暴露出的“抽象、拥挤、不够顺滑”继续压缩为更直接的任务流。

## 本轮变化

- 增加公开投影驱动的首分钟导航：问事实、查证据、做证明。
- 手机推断改为“解释 / 推理板 / 事件链 / 提交”四步，一次只处理一个任务；桌面仍保留完整调查密度。
- 证据、推理板、时间链和 AI 设置按需加载；默认关闭 AI 时，请求与校验适配器不进入首屏脚本。
- transcript 长记录使用延迟渲染，设置抽屉限制滚动穿透，表单补齐名称、长度上限和焦点样式。
- BYOK 端点拒绝 URL credentials、控制字符、片段和危险端口；模型、Key、问题和响应体均有限制。
- Service Worker 不再运行时写入未知响应，不以忽略查询参数的方式匹配非导航资源，并只清理 v2.0 自身缓存。
- 新增官方 npm registry 的一次性依赖审计、自动体验下界、部署响应头建议和独立 v2.0 验证轨道。

## 冻结与兼容

- `SaveEnvelope.schemaVersion` 仍为 `1`。
- v1.9 的 60 案身份与 canonical hash 必须逐案一致。
- v1.8、v1.9 ZIP 在打包前后复核 SHA-256，v2.0 生成独立目录和 ZIP。
- AI 关闭、无 Key、离线、恶意输出或端点不可用时，全部案件仍由确定性核心完成。

创始人探索性会话仍为 1，正式 Fun Gate 参与者仍为 0。自动化只能建立一致性、可达性、失败关闭、性能和公平性下界，不能证明游戏有趣、界面审美被目标玩家接受、语言理解率、继续游玩意愿或市场适配。
