## 内容完成度

当前案件目录为 C01–C12，共 12 案。C10–C12 分别覆盖：

- C10《只响了一次的电话》：PBX 内部回放、外部线路和真实呼叫端点的区分。
- C11《借来的签名》：印章压印、碳复写压力、签署人在场时间和文书封存顺序。

## 真人评测准备

已新增 [final-human-evaluation-kit.md](./final-human-evaluation-kit.md) 和 `aggregate:fun-gate` CLI：

```powershell
npm run aggregate:fun-gate -- test-data/fun-gate
```

工具只读取本地匿名会话导出，输出结案率、无提示结案率、回放率、歧义恢复率和平均时长，不读取案件真相，也不联网。当前没有真实测试数据，因此输出状态为 `insufficient-human-sessions`，不能宣称 Fun Gate 或市场验证通过。

## 当前发布判断

技术与内容质量已达到 12 案内部发布候选，但产品仍未达到公开发布门槛。下一步是招募不知道答案的测试者，先执行 C01 Fun Gate，再根据结果修订共享交互和三案布局，最后抽测 C02–C12 的内容公平性。
