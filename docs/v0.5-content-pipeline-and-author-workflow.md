# TURTLE SOUP v0.5：九案内容管线与作者工作流

验证日期：2026-08-23

## 本轮交付

v0.5 将案件档案扩展为 C01–C09，并保持同一套确定性 `mystery-core`、Worker 边界、存档协议和 React DOM 调查台。C07–C09 的表现层分别是钥匙回收档案、录音来源实验室和雨停后的水痕调查台；案件真相不由模型生成或裁决。

新增案件：

- C07《会自己归位的钥匙》：维修缆线、磁头和配重形成闭合回收路径，监控排除人进入。
- C08《没有人签收的录音》：录音先写入缓冲区，设备断电后才恢复和播放，创建时间与播放时间分离。
- C09《雨停后仍在滴水的房间》：天沟储水沿夹层排水管延迟排出，雨停不等于内部水流立即停止。

每个新案均有独立 JSON、150+ 中文问题语料、测试向量、内容评审记录和 SVG 场景资产。

## 作者工作流

```text
真相图 → 证明义务 → 公开叙事 → 问题语料 → 对抗审查 → 作者报告
```

使用：

```powershell
npm run author:case -- content/zh/cases/c09-rain-room.json
npm run validate:case -- content/zh/cases/c09-rain-room.json
npm run validate:cases
```

`author:case` 现在会直接加载同目录的 `*-question-corpus.ts`，因此支持 `flatMap`/wrapper 生成式语料，不再把语料误报为 0。报告包含结构数量、问题覆盖率、必要证据/替代理论/回放覆盖率、歧义率、重复问题率、解题时长和下一步作者待办。

## 自动化结果

- `npm run check`：31/31 核心与运行时测试通过。
- `npm run validate:cases`：C01–C09 全部 `errors = 0`；九案问题覆盖率均为 100%，语料均达到 150 条门槛。
- `npm run build`：Next.js 生产构建通过，生成首页和九个静态案件路由。
- 反泄漏测试覆盖玩家投影、隐藏事实 ID、内部事件 ID、canonical hypothesis ID 和证明证书字段。
- C07/C08/C09 均加入完整通关、替代理论失效和证据顺序收敛测试。

作者报告中仍允许非阻塞 warning（例如某些开场证据同时关联后续事实）；这些 warning 必须在进入公开版前由内容作者决定是拆分证据来源还是调整默认状态。

## 真人评测策略

按当前产品决定，v0.5 不把真人环节设为开发阻塞。最终 12 案候选冻结后，再统一进行不了解答案的目标玩家评测，并用 Fun Gate 作为发布门槛。此期间所有案件保持 `draft`/内部候选状态，不标记为 `published`。
