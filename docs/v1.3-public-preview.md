# TURTLE SOUP v1.3：60 案科学复杂系统公开预览候选版

状态：`public-preview / human-evaluation-pending`

本版本冻结 C01–C36 的真相、canonical hash、证明证书和旧存档兼容性，新增 Season 4 的 C37–C60。核心仍是确定性 `mystery-core` + Web Worker + 静态 Web/PWA；本地模型和远程服务不参与事实匹配、证明或胜负。

## 当前候选版

- 总案件：60；Season 4 新增 24 案。
- Season 4 语料：5,280 条，包含口语、时间/空间限定、歧义和 fail-closed 问题。
- 新推理板：校准曲线、控制回路、信号链、网络拓扑、不确定性带、参照系、队列模型。
- 每个 Season 4 案件具备两套最小证明集合、替代理论、红鲱鱼和至少六拍回放；C60 具备双章节和三板综合结案。
- 完整预览 ZIP：`dist/turtle-soup-v1.3-public-preview-web-pwa.zip`。
