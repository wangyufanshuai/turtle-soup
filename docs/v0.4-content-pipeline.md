# TURTLE SOUP v0.4 内容生产管线记录

验证日期：2026-08-23

## 内容管线

批量 `validate:cases` 现在覆盖 C01–C06，并检查：

- dangling references、开场提前泄漏和开场证据来源一致性
- 查询语料归一化、预期 query 映射和 150 条最低语料门槛
- 替代理论数量与矛盾覆盖
- 红鲱鱼存在性
- 证明回放覆盖率和最小证明证据覆盖率
- 歧义率、重复问题率和估计解题时长
- 案件 ID、内容 hash 和案件本地化 key 的跨案件唯一性

`validate-case` 现在可以直接读取 `.json` 或 `.ts` 问题语料文件。

## 新案件

### C04《寄不到的回信》

文档来源、邮戳机日期偏移、校准信封、邮袋封存和未离开邮局。

### C05《第三盏未接通的灯》

停电、应急灯、门外信标、反光板、电路拓扑和观察角度。

### C06《一张不存在的船票》

闸机离线队列、同步时间、货运/船员通行证类别和渡轮离港边界。

每案均包含 8 个事件左右、11–12 个事实、9 件证据、两个错误理论、一个红鲱鱼、五拍证明回放和 170 条中文问题语料。
