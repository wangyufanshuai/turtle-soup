# TURTLE SOUP v2.1 · Experience Continuity Internal RC

状态：`internal-rc / human-evaluation-pending`

本候选版在不改变案件真相、证明证书、canonical hash、胜负逻辑或 `SaveEnvelope.schemaVersion: 1` 的前提下，完成了体验连续性加固：案件级工作区与推断步骤恢复、键盘快捷键、提问草稿保留、已解决案件自动回到证明回放、中文操作词汇和可访问焦点状态。

## 验证轨道

- 发行 profile：`v2.1-internal-rc`，60 案；
- 构建：Next.js 静态导出 + Web Worker + IndexedDB/PWA；
- 浏览器：Chromium、Firefox、WebKit；桌面 `1440×900`、手机 `390×844`；
- 自动化：类型检查、核心测试、路由/流程、离线恢复、性能、反泄漏、存档重放和本地依赖审计；
- 真人参与：正式 Fun Gate `0`；创始人探索性会话 `1`；
- 限制：自动化不能证明乐趣、审美、节奏、理解率、留存或市场适配。

## 关键交互合同

1. 首次进入明确引导“先问一个可验证的问题”；
2. 工作区可用 `1`/`2`/`3`/`4` 切换，`/` 聚焦提问；
3. 未识别、歧义和撤销不把玩家锁入不可逆状态；
4. 问题草稿在切换区域和失败后保留；成功回答后才清空已提交草稿；
5. 我的真相只保存在本机，不参与胜负、不发送给 AI；
6. 结案后并排展示玩家解释和证据回放，精通挑战按固定顺序轮换；
7. 完整 `CaseFile` 只在 Worker，React 仅接收 `PlayerProjection`。
