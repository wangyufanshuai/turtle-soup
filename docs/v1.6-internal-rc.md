# TURTLE SOUP v1.6 · 黑箱合成玩家与叙事质量门禁 RC

状态：`internal-rc / human-evaluation-pending`  
真人参与：`0`

v1.6 不增加案件，也不修改 C01–C60 的事件、事实、证据关系、证明证书、canonical hash、胜负逻辑或 `SaveEnvelope.schemaVersion = 1`。

## 本轮变化

- 新增只接收 `PlayerProjection`、`GameEvent` 与 `SaveEnvelope` 的黑箱合成玩家协议；12 类 persona 完成 60 案共 720 条公开命令轨迹。
- 黑箱玩家不得读取 `CaseFile`、证明证书、隐藏事实、内部事件 ID 或 canonical save；C01 通过公开事件组合搜索完成，不含案件特例答案。
- 修复歧义确认协议：`interpretation_required` 会保留待确认状态，但不计入可保存命令，确认后才产生确定性回答。
- C01–C60 建立统一语言审计：12,839 条作者语料、15,274 条有效审计样本、1,175 条运行时 alias、360 条明确歧义；每案口语不少于 8 条、错字/省略合计不少于 8 条、明确歧义不少于 6 条，并含否定、反问、复合、时间、空间和直接索答安全关闭。最大规范化重复率约 4.09%。
- 增加叙事质量代理报告，覆盖问题有效率、重复率、歧义恢复、错误理论、证明集合重叠、红鲱鱼、推理板熵、回放密度、文本和结构相似度。
- 浏览器矩阵覆盖 60 案、Chromium/Firefox/WebKit、1440×900 与 390×844：360 条路由、Chromium 120 条全案完整流程、Firefox/WebKit 48 条黄金完整流程、194 张截图、15 种推理板真实操作、0 控制台错误、0 横向溢出、0 sticky 底栏遮挡，并验证模态焦点、证明缺口、结案回放、刷新与离线恢复。
- 运行时 alias 注册表保持精简，审计压力样本不进入发布包；初始 JavaScript 与最大单文件继续满足既有预算。
- 连续两次构建与两次确定性 ZIP 打包逐字节一致；v1.0–v1.5 历史工件 SHA-256 保持不变。

## 限制

自动化只能证明确定性一致性、公平性下界、公开协议可达性、语言安全关闭、浏览器可操作性、离线恢复、反泄漏和工程可重建性。它没有证明乐趣、叙事感染力、审美偏好、真人理解率、留存或市场适配。正式真人 Fun Gate 仍为 pending。

叙事风险代理没有发现结构阻断或跨案高相似度；C25、C37 的合成玩家问题有效率被标为相对高风险，必须保留到未来真人测试观察清单，不能据此宣称已解决节奏或理解问题。
