## 部署

1. 解压 `dist/turtle-soup-v1.3-public-preview-web-pwa.zip` 到静态托管目录。
2. 保持目录结构、扩展名和 trailing-slash 路由不变。
3. 将所有未知路径交给 `404.html`；不要把未知案件回退到 C01。
4. 使用 HTTPS 托管，以启用 Service Worker 离线缓存。缓存身份为 `black-soup-v13-preview-1`。
5. 当前未执行 DNS、托管或外部发布；需要域名和明确授权后再部署。
