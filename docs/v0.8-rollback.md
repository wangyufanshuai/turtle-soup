# TURTLE SOUP v0.8 回滚说明

1. 保留上一个完整静态目录和 `release-manifest.json`。
2. 部署必须原子替换整个目录，禁止只覆盖 HTML 或单独覆盖 Worker。
3. 若发现阻断问题，恢复上一目录与上一版 `sw.js`；客户端继续由旧 Service Worker 和旧缓存服务。

6. 回滚后重新执行 `npm run check`、`verify:freeze`、`audit:static` 和 `scan:release`。
