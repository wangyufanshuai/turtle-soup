# TURTLE SOUP v2.2 · Cognitive Friction Internal RC

状态：`internal-rc / human-evaluation-pending`

本候选版在不改变 C01–C60 的真相、事件、事实、证明证书、canonical hash、胜负逻辑或 `SaveEnvelope.schemaVersion: 1` 的前提下，降低第一分钟和组织证明阶段的认知摩擦。

## 本轮加固

- 提问区直接显示三个公开第一问起点；点击只填入输入框，不自动消耗问题；
- 问题草稿在同一浏览器会话刷新后继续保留；
- “新证据”不再误算为“已经检查”，调查进度只认实际打开过的材料；
- 证据接入后提供直接进入证明整理的桥接操作；
- 推断区持续显示暂定解释、推理板槽位、事件链和证明证据的公开结构；
- 无推理板案件使用三步推断导航，有推理板案件保持四步；
- 提交前检查只描述玩家已放置的公开结构，不判断答案正确，也不读取隐藏证明义务。

## 验证边界

- 60 案均通过冻结身份、存档重放、反泄漏和确定性结案回归；
- 浏览器目标为 Chromium、Firefox、WebKit，桌面 `1440×900` 与手机 `390×844`；
- AI 继续默认关闭、按需加载；无 Key、离线或端点失败不阻断案件；
- 正式 Fun Gate 参与者仍为 `0`，创始人探索会话为 `1`；
- 自动化不能证明乐趣、审美、节奏、理解率、留存或市场适配。
