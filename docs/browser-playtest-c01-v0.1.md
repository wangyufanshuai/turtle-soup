# C01 浏览器回归记录

测试日期：2026-08-22  
运行方式：Next.js 本地开发服务 `http://localhost:3000/` + 应用内浏览器  
实现路径：React DOM + Worker 确定性核心；不使用 Phaser/Three.js

## 桌面 1440×900

- 首屏在核心初始化后出现，三栏调查台同时可读。
- 左栏显示现场、可检查地点和开场证据；中心栏显示主持说明、输入框和问题构建器；右栏显示两个未结论化的理论草稿。
- 开场投影不包含“手机震动”“正确延时路径”或内部事实/事件 ID。
- 点击“敲门声是人敲的吗？”返回 `信息不足`，回答写入中心记录，不改变隐藏事实。
- 本地存档状态显示“本地已保存”。刷新后问答记录恢复。
- 视觉检查：中心主要行动清晰；右栏没有管理后台统计感；场景图保留足够冷藏室氛围。

## 手机 390×844

- 顶栏压缩为品牌和设置入口；三栏转为底部“现场 / 提问 / 推理”单栏导航。
- 现场页的主场景、案件表面和证据卡可滚动；底部导航保持可用。
- 切换“提问”后输入框、快捷问题和构建器均可见，没有横向溢出。
- 触摸按钮尺寸和高对比边界足以辨认；重要状态同时有文字和颜色。

## 本次修复

1. 事件投影不再由开场可见事实直接生成，必须由玩家发现证据来源后进入时间链。
2. 正确理论不会在开场以“canonical”或正确答案文本出现；它在物理证据出现后才可选择。
3. C01 证明回放补齐锁门后无进入事实，证明回放覆盖率达到 100%。
