# TURTLE SOUP v1.4 · Content Authenticity RC

状态：`internal-rc / human-evaluation-pending`

本版本冻结 C01–C60 的真相图、事件、事实、证据关系、证明证书、canonical hash、旧 SaveEnvelope 和胜负逻辑。v1.4 只增加公开文案 presentation patch、合成理解审计、推理板行为契约和发行验证工具，不宣称通过真人 Fun Gate，也不宣称已证明好玩。

## 自动化门禁

- 60/60 案结构、引用、反泄漏和回放检查。
- 720 条合成会话轨迹（12 类合成玩家 × 60 案）。
- 60 案自然问题路径与歧义 fail-closed 检查。
- 60/60 案自然首问、占位文案、证据语义重复和跨案 n-gram 检查。
- C01、C13、C25、C37、C48、C60 的谜面、证据、问题、错误理论、缺口、章节、回放与视觉语言逐字段深修。
- 最小证明必要性、必要证据删除、红鲱鱼可选性检查。
- 每案执行两条证明顺序；冻结的 C01–C12 只有一份不可变证书，因此第二条为同一最小集合的逆序收敛验证，报告会明确记录而不伪称第二份证书。
- v1.4 presentation patch 为缺失定义的冻结案件补齐三种公开重玩挑战；标准证明证书与 SaveEnvelope 身份保持不变。
- 三浏览器（Chromium、Firefox、WebKit）和桌面/手机静态路由检查。
- 初始 JavaScript、静态包、最大资源和 Service Worker cache identity 检查。
- Worker/投影/存档/诊断输出反泄漏扫描。
- v1.0–v1.3 工件 SHA-256 保留检查。

## 运行顺序

```text
npm run generate:v14:patches
npm run check
npm run build
npm run audit:v14:content
npm run audit:v14:synthetic
npm run audit:v14:performance
npm run scan:v14
npm run audit:v14:browsers
npm run audit:v14:visual
npm run package:v14
npm run verify:v14
```

输出报告位于 `docs/v1.4-*.json`，候选包为 `dist/turtle-soup-v1.4-internal-rc-web-pwa.zip`。不覆盖任何历史 ZIP。

## 明确限制

自动化只能证明一致性、公平性下界、可达性、兼容性和发布卫生。它不能替代真人对理解率、乐趣、节奏、美术、声音或市场竞争力的判断。真人参与数固定为 `0`；后续正式发布前仍需冻结 C01 Fun Gate，再分层抽测其余案件。
