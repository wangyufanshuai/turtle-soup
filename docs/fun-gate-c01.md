# C01 Fun Gate：盲测执行包

这是一个本地、无远程追踪的首案盲测方案。测试者不应提前读取 `content/zh/cases/c01-cold-room-knock.json`、测试向量或答案讨论。

## 测试前

- 使用干净浏览器上下文或设置面板中的“重新开始案件”。
- 屏幕尺寸各测一次：1440×900 与 390×844。
- 关闭开发者工具、源码、网络面板和任何自动提示。
- 只告诉玩家：“你要调查一个短案件，可以提问、检查证据、建立因果链并提交证明。”
- 不解释 `yes/no` 之外的答案代码，也不告诉玩家正确问题。

## 记录表

每位玩家一行，时间用秒记录：

| 字段 | 记录方式 |
|---|---|
| player_id | 随机匿名编号 |
| viewport | desktop / mobile |
| understood_question_loop | 0/1：是否在第一次回答前理解提问是在验证事实 |
| first_action_seconds | 首次有效操作所需秒数 |
| completed | 0/1 |
| solved_without_hint | 0/1 |
| solve_seconds | 从首个有效操作到结案 |
| question_count | 有效提问次数 |
| ambiguity_recovery | 0/1：遇到歧义后是否能继续 |
| wrong_theory_count | 被否定或主动放弃的理论数 |
| replay_opened | 0/1 |
| proof_felt_better_than_reveal | 1–5 |
| friction_category | case / fairness / language / interaction / presentation |
| verbatim_quote | 玩家原话，不改写 |

## 主持人禁止行为

- 不说“你应该问手机/托盘/样本”。
- 不纠正玩家的推理，只记录他们卡住的位置。
- 不在失败理论后解释正确事件。
- 只能在玩家无法操作时解释按钮含义，不解释案件事实。

## 结束访谈

依次问：

1. 你认为自己是在猜答案，还是在证明一条事件链？什么时候形成这个判断？
2. 哪一次提问或证据让你最接近真相？为什么？
3. 你有没有觉得系统在隐藏规则、偏袒某条理论或突然泄底？
4. 提交失败时，你希望得到更多信息，还是更清晰的缺口类型？
5. 结案回放是否让你觉得“我证明了它”，而不是“游戏告诉了我”？

## 通过门槛

- 80% 理解提问循环；
- 70% 在 5–20 分钟内形成正确因果链；
- 60% 无答案提示完成正式证明；
- 70% 将满足感归因于证明过程；
- 语言匹配导致中断不超过 20%；
- 0 次不可逆错误状态；
- 至少 3 人主动尝试备选理论或打开回放。

未达标时只修改 C01、提问语料、反馈和节奏；不要先批量制作 12 案。
